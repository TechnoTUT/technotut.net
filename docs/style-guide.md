# スタイル・デザイン規約 (Design System & Styling Guide)

豊橋技術科学大学 音楽技術部 (TechnoTUT) 公式Webサイトのデザインシステムおよびスタイリング規約です。  
新規コンポーネントの作成や既存ページの修正を行う際は、本規約に沿って実装してください。

---

## 1. カラーパレット

| 用途 | クラス名 / 値 | 説明 |
| :--- | :--- | :--- |
| **全体背景色** | `bg-dark` (`#050505`) | 真っ黒に近い上品なダークテーマ。画像コンテナ背景も原則統一 |
| **パネル / カード** | `bg-dark-panel` (`#0c0c0c`) | コントラストを抑えたわずかに明るいダークトーン |
| **アクセント / ブランド** | `brand` (`#C7000A`) | 部のシンボルカラー。リンクホバーや重要アクセントに使用 |
| **プライマリテキスト** | `text-white` | 見出し、メインタイトル、強調 |
| **セカンダリテキスト** | `text-gray-dim` (`#D0D0D0`), `text-gray-400` | 本文、詳細説明文、補足 |
| **ボーダー / 境界線** | `border-white/10` | 控えめな枠線（ホバー時は `hover:border-white/20` または `30`） |

---

## 2. タイポグラフィ

フォントファミリーは用途に応じて使い分けます。

- **欧文・見出し・英数字**: `font-quicksand` (`'Quicksand', sans-serif`)
  - セクション大見出し、ナビゲーション、英字サブタイトル、日付など
  - 字間は `tracking-wide` や `tracking-widest` を好んで使用
- **和文・本文**: `font-zen` (`'Zen Kaku Gothic Antique', sans-serif`)
  - 日本語の文章、リード文、説明項目
  - 文字の太さは `font-light`（細め）を基本とし、軽快で清潔感のある印象を維持

---

## 3. デザインフィロソフィー

1. **フレームレスでミニマルな構成**:
   - 過剰なボックス枠線や背景の塗り分けを排し、余白とタイポグラフィの美しさで区切るスタイルを推奨します。
2. **シャープで直線的な造形（角ばったデザイン）**:
   - カードや画像コンテナに角丸（`rounded`）は使用せず、直角・シャープなエッジで構成します。
   - 余計な丸みを排し、ソリッドで洗練された印象を維持します。
3. **滑らかなインタラクション**:
   - ホバーエフェクトには `transition-all duration-300` 等を用い、極端な変化を避けて上品なマイクロインタラクションを提供します。
4. **共通コンポーネント / スタイル**:
   - ボタンには `assets/css/main.css` で定義されている共通ボタンスタイル `.common-btn` を使用します。
